МЕНЮ
CALIBRATE
4 точки по манометру: 0 (шланг открыт), ~1, ~2, ~3 bar. Качает сам до точки, ждёт, ты вводишь показание манометра поворотом и нажатием. Итог: наклон датчика, ноль, точность. Нажатие во время качки: отмена.
SENSOR
Живые вольты датчика и пина, давление. Для стенда.
UNITS: bar / psi
Нажатие переключает. Режимы, CUSTOM и давление показываются в выбранных единицах.
TYRE: 255/75R17 / 285/70R17
Нажатие переключает. Объём воздуха 210 / 248 л; выученные поправки пересчитываются по объёму, обучение не сбрасывается.
OFFSET: AUTO / 0.05–1.50 bar
Поправка датчика во время подкачки. AUTO = учится сама. Нажатие: редактировать, поворот, нажатие: сохранить.
SETTLE: AUTO / 1–10 s
Пауза перед замером. AUTO = ждёт, пока давление успокоится.
SCREEN
Поворот картинки: WIDE · PORTRAIT · WIDE 180 · PORTRAIT 180.
RESET LEARNING
Нажать 2 раза за 3 с (первое нажатие: PRESS AGAIN). Сбрасывает обучение подкачки и спуска, калибровка по манометру остаётся.
WIFI: UPDATE + LOG
DinMeter поднимает Wi-Fi WranglerAir, пароль jeepjeep. В браузере 192.168.4.1: залить прошивку .bin, скачать лог CSV, очистить лог. Компрессор и клапан выключены. Долгое нажатие: выход.
VERSION
Версия, шина и объём воздуха, выученные поправки подкачки, τ спуска.
EXIT
Назад на главный экран.
