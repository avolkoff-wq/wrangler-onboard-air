МЕНЮ
CALIBRATE
4 точки по манометру: 0 (шланг открыт), ~1, ~2, ~3 bar. Качает сам до точки, ждёт, ты вводишь показание манометра поворотом и нажатием. Итог: наклон датчика, ноль, точность. Нажатие во время качки: отмена, hold: отмена. Подсказки: press when ready: next hold: abort, press: abort, turn + press: next hold: abort.
LEARN
LEARN INFLATE (компрессор 15 с) · LEARN DEFLATE (клапан 20 с, только с клапаном) · BACK. Нужно > 0,15 bar (иначе CONNECT SYSTEM), для спуска ≥ 1,5 bar (иначе PUMP UP TO 1.5 FIRST). Подтверждение press: start hold: back, для LEARN INFLATE так же: мотор заглушен или нет модуля, то ENGINE OFF / NO VOLTAGE и ещё одно нажатие (ENGINE CONFIRM). Замер, импульс, замер; спуск ставит τ сразу, подкачка учится как первый импульс. Экран как в работе, статус LEARN 12.3s, press: STOP. Итог: τ или rate, press: back.
SENSOR
Живые вольты датчика и пина, давление. Для стенда. press: back.
OUTPUT TEST
COMPRESSOR (K1) · VALVE (K4, только с клапаном) · BACK. Нажатие: один импульс 1 с на выход, потом выключено, второй выход принудительно выключен, во время работы нельзя. Живое давление и вольты, K1 PULSE / VALVE PULSE. press: 1 s pulse turn: choose hold: back. Лог OUTPUT_TEST.
[ ] DEMO
Виртуальные колёса для стола. Не сохраняется, после включения всегда выключен, справа вверху горит DEMO.
UNITS: bar / psi
Нажатие переключает. Режимы, CUSTOM и давление показываются в выбранных единицах.
TYRE: 255/75R17 / 285/70R17
Нажатие переключает. Объём воздуха 210 / 248 л; выученные поправки пересчитываются по объёму, обучение не сбрасывается.
OFFSET: AUTO / 0.05–1.50 bar
Поправка датчика во время подкачки. AUTO = учится сама. Нажатие: редактировать, turn: change press: save hold: back.
SETTLE: AUTO / 1–10 s
Пауза перед замером. AUTO = ждёт, пока давление успокоится.
[x] VALVE
Клапан спуска стоит: DEFLATE, LEARN DEFLATE, OUTPUT TEST VALVE. Сохраняется.
[x] VOLT CHECK
Читать AUX1 с модуля 0-25 V: мотор работает / заглушен, защита ERR LOW VOLTAGE ниже 11,5 В под компрессором.
[x] ENGINE CONFIRM
Третье нажатие перед подкачкой, если мотор заглушен или напряжения нет.
SCREEN
Поворот картинки: WIDE · PORTRAIT · WIDE 180 · PORTRAIT 180.
RESET LEARNING
Нажать 2 раза за 3 с (первое нажатие: PRESS AGAIN). Сбрасывает обучение подкачки и спуска, калибровка по манометру остаётся.
WIFI: UPDATE + LOG
DinMeter поднимает Wi-Fi WranglerAir, пароль jeepjeep. В браузере 192.168.4.1: залить прошивку .bin, скачать лог CSV, очистить лог. Компрессор и клапан выключены. hold: exit.
WIFI PASSWORD
8 знаков A-Z / 0-9: поворот меняет знак, нажатие дальше, на восьмом сохраняет. По умолчанию jeepjeep. Wi-Fi сам выключается через 10 мин без запросов.
VERSION
Версия, шина и объём воздуха, выученные поправки подкачки, τ спуска. press: back.
HOURS
Моточасы ч:мм: compressor total, since cleaning (сбрасывается при чистке фильтров), клапан. press: back hold: filters cleaned, затем подтверждение hold 2 s: reset service press: back. После 10 ч с чистки на главном экране оранжевое CLEAN FILTERS (не блокирует).
EXIT
Назад на главный экран.
