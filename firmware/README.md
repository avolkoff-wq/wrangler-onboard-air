# Прошивка

## Сборка и прошивка

| Способ | Как |
|---|---|
| Готовый файл | `bin/wrangler_air.bin`: залить через меню UPDATE (Wi-Fi) или esptool по USB-C |
| Arduino IDE | открыть `wrangler_air/wrangler_air.ino`, плата M5Stack StampS3 (DinMeter), библиотека M5Unified, разметка памяти с двумя OTA-разделами, USB CDC On Boot: Enabled |
| PlatformIO | `pio run`, прошить: `pio run -t upload` |

**Одна прошивка (с 0.5.0)** под схему C (`power_schematic_def.png`): датчик 0-3,3 V прямо на G13, Unit 2Relay на PORT.B (G2 компрессор, G1 клапан), модуль 0-25 V на G15. То, что раньше было отдельными сборками, теперь в меню:

| Пункт меню | Что делает | Сохраняется |
|---|---|---|
| `[x] VALVE` | клапан спуска стоит: DEFLATE, LEARN DEFLATE, OUTPUT TEST VALVE. Без галки выход клапана всегда выключен | да |
| `[ ] DEMO` | виртуальные колёса вместо датчика, для стола. Справа вверху горит DEMO | нет, при каждом включении выключен |
| `[x] VOLT CHECK` | читать AUX1 через модуль 0-25 V | да |
| `[x] ENGINE CONFIRM` | третье нажатие перед подкачкой, если мотор заглушен или напряжения нет | да |

Старый вариант с датчиком 0,5-4,5 V через делитель на G1 убран: у него G1 и G13 поменяны местами, и неверный выбор в меню подал бы сигнал на ножку, куда подключён выход датчика.

Особенности варианта A:
- 0 bar = 0 V, поэтому обрыв не виден по напряжению. Пин G13 подтянут к земле, обрыв читается как 0 bar,
  и его ловят две проверки: компрессор работает 3 с, а датчик меньше 0,1 bar → ошибка SENSOR; нет роста 0,1 bar за 60 с → LEAK.
- Выше 3,10 V (≈ 11,3 bar) → ошибка датчика.
- G13 на ADC2: при включённом Wi-Fi не читается. Wi-Fi включается только в режиме UPDATE, выходы при этом выключены.
- Выхода K4 (спуск) в этой сборке нет: PORT.A занят датчиком.

**Температура воздуха не учитывается.** При большом перепаде T давление меняется примерно на 0,3 %/°C. Learning частично компенсирует это на реальной системе.

## Спуск (вариант C)

- Цель выбирается ручкой из типовых давлений (`config.h` PRESETS): HIGHWAY 2.5, ROUGH ROAD 1.8, GRAVEL 1.5, TRAIL 1.2, ROCK 1.0, SAND 0.8, RECOVERY 0.5 bar и последним CUSTOM, своё значение (по умолчанию 2,0 bar), во всех сборках. На CUSTOM нажатие сначала открывает значение: ручкой шаг 0,1 bar, нажатие сохраняет и взводит старт, долгое нажатие отменяет. Ниже 0,8 bar на экране `LOW` (без бэдлоков шина может сойти с диска).
- Старт в два нажатия (см. «Управление»), потом замер статики. В пределах ±0,1 bar от цели ничего не делает (`OK, WITHIN 0.1`). Ниже цели качает компрессором (`INF`), выше спускает клапаном (`DEF`).
- Спуск: клапан открывается на время t = τ · ln(p_абс / p_цели_абс), закрывается, пауза, замер, при необходимости ещё (до 4 раз).
  Первый спуск, пока τ не выучена, проходит только 60 % пути. Если спустил ниже цели, добивает короткой подкачкой компрессором.
- Компрессор и клапан никогда не включены вместе. При пропадании питания клапан закрыт (NC).
- Две независимые калибровки: подкачка (offset, c, rate, kTop, bias, dev) и спуск (τ). Обе уточняются на каждом обычном цикле.
